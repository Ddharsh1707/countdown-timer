# Countdown Timer

Counts down the days, hours, minutes and seconds to any date and time.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/countdown-timer.git
```
